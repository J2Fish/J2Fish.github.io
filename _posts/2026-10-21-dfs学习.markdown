# dfs-stack-stimulation-learning

stackstimulation need 3 more things:

1. it - to record which line each point at **!** need initialization
2. visited - to record which nodes had been visited
3. stack - to record backward order
   the first two are to solve the problem that we will visit the same point/line. When we use implicit stack ,traversal will help us avoid visiting the same line but point also need our rule

here are dfs_front codes:

